# Home Workout

A 20-minute guided bodyweight workout app with animated stick figures, a countdown timer, audio cues, and wake lock support.

**Live app:** https://ajai8085.github.io/home-workout

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- No external UI libraries

## Development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Builds and publishes to the `gh-pages` branch. GitHub Pages serves from there automatically.
